# 악보연습 (안드로이드)

- 악보 PDF 보관함: 작곡가·제목 지정, 검색, 작곡가순 정렬
- 가져오기: + 버튼 → 휴대폰 저장소나 구글드라이브에서 PDF 선택
- 넘기기: 오른쪽에서 왼쪽으로 밀면 다음 쪽, 반대로 밀면 이전 쪽 (메뉴에서 방향 변경 가능)
- 연습 범위: [범위] → 손가락으로 네모 그리기 → 이름·목표 횟수
  - 아래 초록 막대의 [+1] [−1] 버튼으로 횟수 입력 (◀ ▶ 로 같은 쪽의 다른 범위 선택, 범위를 눌러도 선택)
  - 범위를 길게 누르면 수정·기록 보기
  - [레이어]에서 레이어(예: 1주차, 왼손)를 만들어 범위를 따로 묶고 보이기/숨기기
- 필기: 화면을 두 번 두드리면 필기 시작, 다시 두 번 두드리면 끝 (검정·빨강·파랑·형광펜·지우개·되돌리기)
- 확대·축소: 두 손가락으로 벌리기/오므리기, 확대한 상태에서는 한 손가락으로 이동
- 메트로놈: 위의 ♩ 버튼 → 빠르기 숫자 칸에 직접 입력(기본 100) 또는 −5 −1 +1 +5·탭, 박 수(기본 박없음), ▶ 시작 — 곡마다 빠르기·박 수를 기억, 처음 여는 곡은 가장 최근에 쓴 빠르기로 시작

## APK 받기
GitHub 저장소에 올리면 Actions 탭 → 최신 "Build APK" 실행 → 아래 Artifacts의 ScorePractice-apk 다운로드.
- 색 고치기 (이미 색칠된 (임) 악보용): 위의 [색] → 색 고르기 → 잘못된 음표를 누르면 그 음표의 인쇄된 잉크만 그 색으로 바뀜
  - 음표 크기는 악보의 오선 간격으로 자동으로 맞춤
  - 2분·온음표처럼 속이 빈 음표는 테두리만 바뀌고 안쪽은 그대로
  - "검정(색 빼기)" = 칠해지면 안 되는 음을 다시 검게
  - 고친 음표를 다시 누르면 취소, [레이어]에서 보이기/숨기기
- 손번호: 위의 [손] → 번호를 넣을 곳을 누르고 그대로 밀기 (밀기 시작하면 부채꼴 안내가 뜸)
  - 오른쪽(0°)=1, 약 34°=2, 약 68°=3, 약 101°=4, 135°=5 (각각 ±15°), 왼쪽으로 밀면 손번호 입력 끝, 왼쪽 아래(225°)는 취소
  - 크기는 악보 오선 간격에 맞춰 자동(손번호 막대의 가− 가+ 로 이 곡의 손번호 전체 크기 조절), 번호를 누르면 지우기, 꾹 눌러 끌면 옮기기, [레이어]에서 보이기/숨기기
- 되돌리기·다시 하기: 화면 왼쪽 아래 ↶ ↷ (범위·횟수·필기·색 고치기·손번호 모두), 두 손가락으로 톡 쳐도 되돌리기
- 연습 기록: 아래 초록 막대의 [기록] 또는 ⋯ → 연습 기록
  - 오늘 / 최근 7일 / 연속 연습일 / 목표 달성 수, 최근 14일 막대그래프, 레이어별 보기
  - 범위마다 진행 막대·오늘 횟수·마지막 연습일, 누르면 그 쪽으로 이동
  - 보관함 목록에도 곡마다 "오늘 n회 · 총 m회 · 마지막 연습" 표시
- PDF로 저장: ⋯ → PDF로 저장 → 넣을 것(색 고친 것·필기·손번호·연습 범위) 고르기 → 저장 위치(휴대폰 또는 구글드라이브) 고르기
- 저장·백업 (첫 화면 오른쪽 위 ⋮)
  - 저장 폴더 지정: 휴대폰 폴더(예: Documents/악보연습)를 정하면 악보·연습 기록·필기 등이 자동으로 그 폴더에도 저장됨 → 앱을 지우고 다시 깔아도 같은 폴더를 고르면 그대로 불러옴
  - 백업 파일 만들기: 모든 악보와 기록을 .zip 하나로 저장 → 저장 위치로 구글드라이브를 고르면 됨
  - 백업 불러오기: 다른 휴대폰에서 구글드라이브의 백업 .zip을 고르면 합쳐서 불러옴 (같은 악보는 백업 내용으로 바뀜)
- 반 페이지 넘김: ⋯ → 반 페이지 넘김 켜기 → 한 화면에 "이번 쪽 아래 절반 + 다음 쪽 위 절반" (단 사이 빈 곳에서 자동으로 나눠 악보가 잘리지 않게)

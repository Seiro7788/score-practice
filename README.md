# 오선노트 (안드로이드 피아노 악보·연습 앱)

- 악보 PDF 보관함: 작곡가·제목 지정, 검색, 작곡가순 정렬
- 가져오기: + 버튼 → 휴대폰 저장소나 구글드라이브에서 PDF 선택
- 넘기기: 오른쪽에서 왼쪽으로 밀면 다음 쪽, 반대로 밀면 이전 쪽 (메뉴에서 방향 변경 가능)
- 연습 범위: [범위] → 손가락으로 네모 그리기 → 이름·목표 횟수
  - 아래 초록 막대의 [+1] [−1] 버튼으로 횟수 입력 (◀ ▶ 로 같은 쪽의 다른 범위 선택, 범위를 눌러도 선택)
  - 범위를 길게 누르면 수정·기록 보기
  - [레이어]에서 레이어(예: 1주차, 왼손)를 만들어 범위를 따로 묶고 보이기/숨기기
- 필기: 화면을 두 번 두드리면 필기 시작, 다시 두 번 두드리면 끝 (펜 검정·빨강·파랑, 형광펜 노랑·초록·분홍·하늘, 굵기 3단계, 형광펜은 자유롭게 긋기가 기본("곧게"를 켜면 직선), 형광펜은 악보 인쇄·펜 글씨 밑으로 들어가 검은 선 색이 덮이지 않음, 지우개)
- 확대·축소: 두 손가락으로 벌리기/오므리기, 확대한 곳 옮기기도 두 손가락으로만 (한 손가락으로 밀면 확대 중에도 쪽 넘김)
- 메트로놈: 위의 ♩ 버튼 → 빠르기 숫자 칸에 직접 입력(기본 100) 또는 −5 −1 +1 +5·탭, 박 수(기본 박없음), ▶ 시작 — 곡마다 빠르기·박 수를 기억, 처음 여는 곡은 가장 최근에 쓴 빠르기로 시작

## APK 받기
GitHub 저장소에 올리면 Actions 탭 → 최신 "Build APK" 실행 → 아래 Artifacts의 ScorePractice-apk 다운로드.
- 색 고치기 (이미 색칠된 (임) 악보용): 위의 [색] → 색 고르기 → 잘못된 음표를 누르면 그 음표의 인쇄된 잉크만 그 색으로 바뀜
  - 음표 크기는 악보의 오선 간격으로 자동으로 맞춤
  - 2분·온음표처럼 속이 빈 음표는 테두리만 바뀌고 안쪽은 그대로
  - "검정(색 빼기)" = 칠해지면 안 되는 음을 다시 검게
  - 고친 음표를 다시 누르면 취소, [레이어]에서 보이기/숨기기
- 손번호: 위의 [손] → 번호를 넣을 곳을 누르고 그대로 밀기 (밀기 시작하면 부채꼴 안내가 뜸)
  - 오른쪽(0°)=1, 약 34°=2, 약 68°=3, 약 101°=4, 135°=5 (각각 ±15°), 왼쪽으로 밀면 손번호 입력 끝, 왼쪽 아래(225°)는 취소
  - 크기는 악보 오선 간격에 맞춰 자동(손번호 막대의 가− 가+ 로 이 곡의 손번호 전체 크기 조절), 번호를 누르면 지우기, 꾹 눌러 끌면 옮기기, [레이어]에서 보이기/숨기기
- 되돌리기·다시 하기: 화면 왼쪽 아래 ↶ ↷ (범위·횟수·필기·색 고치기·손번호 모두), 두 손가락으로 톡 쳐도 되돌리기
- 연습 기록: 아래 초록 막대의 [기록] 또는 ⋯ → 연습 기록
  - 오늘 / 최근 7일 / 연속 연습일 / 목표 달성 수, 최근 14일 막대그래프, 레이어별 보기
  - 범위마다 진행 막대·오늘 횟수·마지막 연습일, 누르면 그 쪽으로 이동
  - 보관함 목록에도 곡마다 "오늘 n회 · 총 m회 · 마지막 연습" 표시
- PDF로 저장: ⋯ → PDF로 저장 → 넣을 것(색 고친 것·필기·손번호·연습 범위) 고르기 → 저장 위치(휴대폰 또는 구글드라이브) 고르기
- 저장·백업 (첫 화면 오른쪽 위 ⋮)
  - 저장 폴더 지정: 휴대폰 폴더(예: Documents/오선노트)를 정하면 악보·연습 기록·필기 등이 자동으로 그 폴더에도 저장됨 → 앱을 지우고 다시 깔아도 같은 폴더를 고르면 그대로 불러옴
  - 백업 파일 만들기: 모든 악보와 기록을 .zip 하나로 저장 → 저장 위치로 구글드라이브를 고르면 됨
  - 백업 불러오기: 다른 휴대폰에서 구글드라이브의 백업 .zip을 고르면 합쳐서 불러옴 (같은 악보는 백업 내용으로 바뀜)
- 반 페이지 넘김: ⋯ → 반 페이지 넘김 켜기 → 한 화면에 "이번 쪽 아래 절반 + 다음 쪽 위 절반" (단 사이 빈 곳에서 자동으로 나눠 악보가 잘리지 않게)
- 메뉴 접기: 위의 ⛶ → 위아래 메뉴(상태 표시줄 포함)가 모두 사라지고 악보만 보임, 화면을 두 번 두드리면 다시 나옴
- 악보 목록: 작곡가별로 묶어서 보임 (작곡가 이름을 누르면 접기/펴기, 검색하면 모두 펼침), 곡 오른쪽 ✎ 로 제목·작곡가 수정, 악보 화면에서는 위의 제목을 눌러 수정
- 필기도 레이어별: 필기 막대 맨 앞 [레이어: …]에서 쓸 레이어를 고르면 그 레이어에 들어가고, [레이어]에서 그 레이어를 끄면 그 필기도 숨겨짐 (예전 필기는 레이어 없이 항상 보임)
- 연주·계이름 (위의 ♪): 처음 한 번 [악보 파일(XML) 연결]로 그 곡의 MusicXML(.musicxml/.xml/.mxl)을 고름
  - 오른손 / 왼손 / 양손, 피아노 / 계이름(도레미로 불러주기) / 계이름+피아노, 마디 범위·반복, 빠르기는 메트로놈 빠르기
  - 도돌이표·1·2번 괄호는 펼쳐서 연주, 계이름은 도=C 고정, 휴대폰 한국어 음성 사용(없으면 "아" 소리)
  - [악보 보기]: 연결한 XML을 악보로 그려 보여 줌 → 시작 마디를 누르고 끝 마디를 누르면 그 구간 재생(같은 마디를 두 번 누르면 끝까지), 재생 중 아무 곳이나 누르면 멈춤, 연주 중인 마디를 파란 네모로 따라감, 아래에서 빠르기 −5 −1 +1 +5·숫자 직접 입력·"악보 ♩=" (악보에 적힌 빠르기), 재생 중에 바꾸면 그 마디부터 새 빠르기로 이어 연주
  - 계이름 노래: 휴대폰 음성(이탈리아어 음성이 있으면 이탈리아어, 없으면 한국어)으로 do re mi fa sol la si를 만들고 PSOLA로 음마다 정확한 높이·길이로 맞춤(사람 목소리 느낌 유지), 높은 선율은 여자·낮은 선율은 남자 목소리(구절 안에서는 안 바뀜), 부를 수 없는 음역은 구절 단위로 옥타브 조정(바흐·스칼라티는 제외), 끊지 않고 이어 부름
  - 코드 분석: 악보 보기에서 박마다 화음을 찾아 마디 위에 코드 이름(C♯m, G♯7, D7/F♯)과 로마 숫자(i, iv6, V7, ♭II43, vii°7 …)를 표시, 조가 바뀌면 "c♯: i"처럼 조 이름을 붙임, [코드] 체크로 켜고 끔
  - 악보 보기 크기: 위의 가− 가+ (악보를 화면 폭에 맞춰 다시 그림), 두 손가락으로 벌려 확대도 됨
  - 악보 보기 반음색: [반음색] 체크 → XML 악보의 ♯·♭·𝄪 음표를 PDF와 같은 색(검은건반/흰건반 구분)으로 칠함
